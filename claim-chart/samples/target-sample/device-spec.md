# サンプル端末 仕様（架空）

> クレームチャートのサンプルで「照らす相手」として使うための、架空の端末の仕様である。
> 実在の製品・会社とは関係がない。

## 1. 端末

| ID | 要求 |
|---|---|
| HW-1 | 端末は、タッチ画面、メモリ、プロセッサを 1 つずつ持つ。 |
| HW-2 | 文字はタッチ画面の上の画面キーボードで入力する。 |

## 2. メモ帳アプリ

| ID | 要求 |
|---|---|
| MN-1 | メモ帳アプリは、メモの本文から、電話番号・メールアドレス・日付を、正規表現の一覧で見つける。 |
| MN-2 | 見つけた文字列に下線を引く。 |
| MN-3 | 下線の文字列を押すと、その種類に合う動作の一覧（電話をかける・連絡先に足す・予定に足す）をポップアップで出す。 |
| MN-4 | 一覧から選んだ動作を、その文字列に対して実行する。 |
| MN-5 | 見つける処理はメモ帳アプリの中の関数で行い、別のプログラムやサーバーには分けない。 |
| MN-6 | 音声では操作しない。 |
| MN-7 | 見つけた文字列は保存せず、本文を表示し直すたびに見つけ直す。 |

## 3. ロック画面

| ID | 要求 |
|---|---|
| LK-1 | 画面ロックのあいだ、ロック画面には時刻だけを出す。鍵や矢印の絵は出さない。 |
| LK-2 | 画面の下端から上へ、指 1 本で画面の高さの 30% 以上払ったら、ロックを外す。 |
| LK-3 | 払うあいだ、画面の絵は動かさない。 |
| LK-4 | 4 桁の暗証番号でもロックを外せる。 |
